## Polish

- **#3 sidebar buttons without accessible name: NOT reproduced.** Rail, header and tab-bar buttons all expose names at
  three widths (aria snapshot, axe `button-name` clean, Lighthouse accessibility 100). Test is XPASS; the coordinator
  can drop the marker or ask B whether it was already fixed.
- No UI path for the 25 MB limit: there is no file picker, only the recorder, so the limit is verified at the API
  (`upload_too_large`, message names 26214400 bytes). Fine today; add a UI check when upload ships.
- Local server has no controllable clock. The reminder journey sets a trigger 3 s ahead on the real clock and clears
  quiet hours first. **The server correctly deferred it under the default 22:00-08:00 quiet hours** (log:
  "suppressed ... inside the user's quiet hours", rescheduled to 12:00Z), which is good behaviour but made my first run
  fail at 22:28 ET. Owner C: a `METIS_CLOCK_*` override for the local API would make this exact and instant.
- Lighthouse console error on the deployed page: one `404` resource load (not reproduced in a plain Playwright load;
  likely favicon/manifest under Lighthouse). Worth a check by B.

## What works well

- First visit to Today is fast, clear and honest: "Free time is unknown ... nothing below claims to have found a gap."
- "Fixture mode" is labelled everywhere it matters (rail, phone header chip, review panel: "fixture: test output, not a
  real model"). Review step says "Nothing below exists yet."
- Unknown values stay empty ("Deadline (needed)"); saving with an unanswered field keeps the item in Inbox rather than
  making it a commitment.
- Settings: a stale-revision save returns 409, the UI says "changed elsewhere. Nothing was overwritten", and the server
  value is untouched.
- Offline capture is held "on this device, not saved"; reconnect replays exactly one capture.
- Reload mid-extraction does not duplicate the capture and the note stays findable.
- Microphone denial gives a clear message and typing keeps working.
- Reminders fire into Alerts and respect quiet hours.
- No horizontal overflow at 390 / 768 / 1280, light or dark; zero failed network calls.
