# Secrets and rotation

Metis needs no Anthropic, OpenAI, speech, vector-SaaS or calendar keys. No
server secret belongs in `apps/web` or a desktop build.

## Inventory

| Secret / key | Purpose | Storage | Rotation |
| --- | --- | --- | --- |
| Speech server secret | API/worker -> loopback speech server bearer | `/etc/metis-speech.env` on the VM (0600), generated by `vm-setup.sh` | delete the file and redeploy |
| Legacy single-user API key | pre-cutover desktop bearer | `/etc/metis-api.env` on the VM (0600); cleared in the running config by `configure-hosted.sh` | delete after the hosted cutover is verified |
| Identity Platform web API key | desktop sign-in | public by design; restricted to Identity Toolkit + Secure Token APIs | in the GCP console |
| Identity Platform tokens | per-user auth | issued by Identity Platform; verified by the API | revoke or disable the user in Identity Platform |
| Desktop auth/speech secrets | local desktop dev only | per-launch; not deployed | n/a |
| Operator GCP credentials | `ops/gcp/*.sh` | `gcloud` login on the operator machine | per account policy |

## If a secret leaks

Rotate immediately; for operator credentials revoke the `gcloud` session first.
Never paste secrets into issues, logs or this repo; logs must not contain
tokens, prompts, transcripts or raw sources.
